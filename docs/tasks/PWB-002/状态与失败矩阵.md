# PWB-002 状态与失败矩阵

起点：干净工作树，61d817aa08b33cf8ea1f483d89fd336943078c00 的父提交为 Formal Base 50bebd2b07619e4e06852ad8a20c110be0553315。冻结源 blob 已逐一匹配 TASK manifest。

| 操作 | canonical / 身份 | 失败或取消 |
|---|---|---|
| schema v2 → v3 | 保留所有原表和 ID，新增 series / exceptions / reminders / memos / unscheduled | 升级前 snapshot；DDL/data/version 一笔事务回滚，停止打开 |
| 动态日期范围查询 | series + 显式 exception；只返回范围内 projection | 无持久化 future occurrences |
| 单次移动/编辑/删除 | series ID + 原 YYYY-MM-DDTHH:mm 不变 | 无效原键拒绝，不动其它 occurrence |
| 整循环编辑 | 同一 series ID，确认后更新定义并清空旧例外 | 存在例外且未确认时拒绝；取消不写入 |
| 整循环删除 | 同事务删除 series/例外/其确认记录 | 不影响其它 series / single / Track |
| 今日确认 | display date + item/occurrence ID | Vector / Reminder / Memo / 非当日来源拒绝 |
| 备份恢复 | 完整 v3 图，旧 v2 在 staging 升级 | 保留 validation / safety / reopen 补偿 |
| 日历 UI | Month / Week / day-detail 使用同一 canonical snapshot 展开 | TA-1A multi-delete / clear 限单次事项 |

L0：日历算术、循环与信息对象契约；L1：动态展开、SQL 结构与校验；L2：原子维护及 Today 派生；L3：主进程公开命令与纯只读日期范围投影。Bootstrap 仅连接 IPC。无新增模块或第二状态库。
