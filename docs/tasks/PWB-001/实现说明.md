## 职责归层

个人状态是此最小纵向的一个业务模块，Tracks / Plan 分表拥有事实，Today 只查询并组合。

| 位置 | 职责 |
|---|---|
| 个人状态/L0_公理层 | 稳定 DTO、日期规则、字段约束、区间语义 |
| 个人状态/L1_器件层 | SQLite 结构、连接、快照与迁移机制 |
| 个人状态/L2_流程层 | Track/Plan 写事务、重叠拒绝、Today 投影和确认 |
| 个人状态/L3_外交层 | 只暴露维护与查询 API，不返回可变连接 |
| 桌面界面/L3_外交层 | IPC 公共类型和 React 展示适配器，仅读取个人状态 L3 契约 |
| Bootstrap | Electron 生命周期、IPC 白名单、preload、React 入口与组合根 |
| scripts / 测试 / docs | 四层之外的工程外围 |

不创建空层。所有跨模块 import 经过双方 L3。lint 中的架构检查检查相对静态 import 方向；测试对内部迁移器的白盒故障注入属于工程外围。

## 具体选择

TypeScript + React + esbuild；系统中文字体，浅色、蓝色强调、键盘可达表单和原生 dialog。UI/UX 技能检索作为建议，仅采用与桌面维护应用相关的对比度、反馈、表单和简洁布局规则，不采用检索返回的 newsletter 页面结构。

Electron 40.0.0 内置 `node:sqlite`，无 ORM、无额外原生 SQLite binding。主进程独占连接，同步短事务；DELETE journal + FULL synchronous；single-instance lock 避免正常启动第二写入进程。Date-only 保持文本日历日期，单次时间为同日本地 HH:mm；系统更新时间使用 ISO instant。

v1 为真实 Track/Plan schema，v2 加入本阶段必须的 acknowledgement。新建库在一笔事务中完成全部当前 schema；旧版使用有序 migration，在升级前生成快照。两版均不含 TA-1B/Future 字段。

Electron Builder 目录打包；Playwright 驱动 packaged exe 的普通 UI，并在 Electron 主进程验证托盘生命周期。原生文件选择器只替换选择结果，备份/恢复 IPC 和数据库逻辑不替换。

## 状态 / 失败矩阵

| 边界 | 失败后 canonical truth |
|---|---|
| 字段无效、关联不存在、Vector 重叠 | 拒绝，事务不提交，原事实不变 |
| 未提交进程中断 | SQLite journal 回滚，已提交事实保留 |
| 备份目标已存在、不可写 | 拒绝，live DB 不变 |
| 候选文件无效、身份/结构/版本/领域数据不符 | 在 live 替换前拒绝 |
| 创建安全快照失败 | 不进入替换，live DB 不变 |
| staging 准备/迁移/验证失败 | 不关闭/替换 live DB |
| 原子替换前进程中断 | 旧库继续 canonical，staging 不是 live truth |
| 原子替换后进程中断 | 已完整验证的新库 canonical，恢复前快照保留 |
| 替换或 reopen 失败 | 尝试恢复安全快照；补偿失败以 AggregateError 使宿主退出，保留 safety |
| 升级步骤/最终验证失败 | DDL、版本、数据一起回滚，open 失败且关闭连接 |

恢复同目录 staging，关闭 live 后使用文件系统原子 rename 替换；不以 JSON 或其它备份文件作为第二份 live truth。安全快照无自动历史 UI 与轮换产品。
